# pkgclean

[English version](README.md)

Интерактивная утилита для терминала: удаление приложений и очистка системы.
Выбираешь приложение из списка (не нужно помнить названия пакетов) и удаляешь
как хочешь: только пакет, с зависимостями или полностью, со всеми остатками.

Работает на **Arch** (`pacman`), **Debian / Ubuntu / Mint** (`apt`) и
**Fedora / RHEL** (`dnf`). Менеджер пакетов определяется автоматически.

## Возможности

- Список установленных пакетов по размеру (большие сверху) с предпросмотром
- По умолчанию только то, что ты ставил сам, флаг `-a` показывает всё
- Выбор нескольких пакетов через `Tab`
- Режимы удаления: только пакет / с ненужными зависимостями / с системными конфигами
- **Полное удаление**: пакет + остатки в `~/.config`, `~/.cache`,
  `~/.local/share`, `~/.local/state`, `~/.var/app`, `~/.имя` (список ты проверяешь сам)
- Симуляция: показывает, что будет удалено, ничего не трогая
- Очистка ненужных зависимостей (сирот)
- Очистка кэшей: пакетного менеджера, yay/paru, журнала systemd, Flatpak

## Установка

> **Статус AUR:** пакет в AUR **временно недоступен**. Arch сейчас закрыл
> регистрацию новых аккаунтов в AUR, поэтому опубликовать пакет пока нельзя.
> Он появится в AUR, как только регистрацию откроют. До этого используй
> способы ниже, они работают так же.

### Любой дистрибутив: из исходников (пока рекомендуется)

```bash
git clone https://github.com/bywrd/pkgclean
cd pkgclean
sudo make install        # ставит в /usr/local/bin
```

Удаление: `sudo make uninstall`. Установка в другое место: `make install PREFIX=~/.local`.

### Arch Linux: собрать пакет из репозитория

```bash
git clone https://github.com/bywrd/pkgclean
cd pkgclean
makepkg -si
```

### Debian / Ubuntu / Mint: .deb

Скачай `pkgclean_*_all.deb` со страницы Releases или собери сам:

```bash
make deb
sudo apt install ./build/pkgclean_*_all.deb
```

### Вручную

```bash
sudo install -Dm755 pkgclean /usr/local/bin/pkgclean
```

### AUR (скоро)

```bash
yay -S pkgclean
```

## Использование

```bash
pkgclean        # пакеты, которые ты ставил сам
pkgclean -a     # все пакеты, включая зависимости
pkgclean -h     # справка
```

Управление: стрелки, набор текста для поиска, `Tab` для выбора нескольких,
`Enter` для подтверждения, `Esc` чтобы вернуться. Нужен `fzf` (скрипт предложит
поставить его сам).

## Что делает каждый режим

| Действие | pacman | apt | dnf |
|---|---|---|---|
| Только пакет | `-R` | `remove` | `remove` (зависимости остаются) |
| С зависимостями | `-Rs` | `remove --auto-remove` | `remove` (чистит ненужные зависимости) |
| С системными конфигами | `-Rns` | `purge --auto-remove` | `remove` |
| Симуляция | `-Rnsp` | `-s purge` | `remove --assumeno` |
| Ненужные зависимости | `-Qdtq` + `-Rns` | `autoremove --purge` | `autoremove` |

Важно: в apt флаг `--auto-remove` удаляет и *другие* ненужные пакеты. Смотри
список, который покажет apt, перед подтверждением.

## Предупреждение

«Полное удаление» стирает файлы в твоей домашней папке. Остатки ищутся по имени
пакета, поэтому для общих названий в списке могут оказаться посторонние вещи.
Утилита показывает список и просит подтверждение, но читай его внимательно.
Сами пакеты удаляет твой менеджер пакетов, и он тоже спрашивает подтверждение.
